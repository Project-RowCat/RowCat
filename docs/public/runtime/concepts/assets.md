# 자산

`@rowcat/runtime`의 `Image`와 `Audio`는 `asset()`이 만든 참조를 받습니다. `asset()`이 받는
값은 두 가지입니다.

```text
asset("characters/sena/smile")               RowCat 자산          스튜디오에 올려 이름을 붙입니다 — 그림과 소리
asset("audio/bgm/main")                      RowCat 자산          같은 이름 공간입니다
asset("https://cdn.example.com/sena.webp")   외부 HTTPS 주소       당신의 CDN에 있는 **그림**입니다
```

**외부 주소는 그림에만 열려 있습니다.** 소리는 RowCat에 올린 것만 울립니다 — 그 이유는
[`Audio`의 원격 주소 절](/docs/runtime/reference/components#원격-주소는-소리가-되지-않습니다)에
있습니다.

둘 중 **RowCat 자산이 권장하는 방법**입니다. 파일이 RowCat에 저장되므로 주소가 만료되지
않고, 당신의 CDN이 필요하지 않으며, 코드에는 바꾸기 쉬운 이름 하나만 남습니다. 외부 주소는
이미 다른 곳에 올려 둔 그림을 쓸 때를 위해 그대로 지원됩니다.

## RowCat 자산

스튜디오의 `자산` 목록에서 파일을 올리고 **이름**을 붙입니다. 코드에서는 그 이름을
`asset()`에 적습니다. `asset("` 까지 치면 스튜디오가 이 작품에 올려 둔 이름들을 제안하고,
코드에 적힌 이름 위에 커서를 얹으면 그 그림을 보여 줍니다.

```tsx example=managed-image file=src/main.tsx
import { Image, Stack, Text, asset } from "@rowcat/runtime";

export default function App() {
	return (
		<Stack gap={12} style={{ padding: 16 }}>
			<Image
				source={asset("characters/sena/smile")}
				alt="세나"
				fit="cover"
				style={{ width: 96, height: 96, borderRadius: 48 }}
			/>
			<Text>세나가 카운터 뒤에서 고개를 들었다.</Text>
		</Stack>
	);
}
```

이름은 당신이 정합니다. `characters/`·`backgrounds/`·`audio/`처럼 폴더 모양으로 적을 수
있지만 그 접두사에 정해진 뜻은 없습니다 — 목록이 읽기 좋아지는 것뿐입니다. **`audio/`도
예약어가 아닙니다**: 소리를 `music/night`이라 불러도 되고 그림을 `audio/…`에 두어도
됩니다(권하지는 않습니다).

- 조각은 영문이나 숫자로 시작하고 영문·숫자·`.`·`_`·`-`만 씁니다.
- 최대 8단계, 200자. `..`·`./` 같은 상위 이동은 거절됩니다.
- **한 프로젝트에서 같은 이름을 두 자산에 붙일 수 없습니다** — 그림과 소리가 **한 이름 공간**을
  나눠 씁니다.

### 그림과 소리

이름 공간은 하나지만 **부르는 프리미티브가 그 이름이 무엇인지 정하지 않습니다.** 이름이
가리키는 것이 그림인지 소리인지는 올릴 때 정해지고, 어긋나면 아무 일도 일어나지 않습니다.

```tsx
<Image source={asset("audio/bgm/main")} alt="" />   {/* 소리 이름 → 자리표시자 */}
<Audio source={asset("characters/sena/smile")} playing />  {/* 그림 이름 → 침묵 */}
```

둘 다 오류가 아닙니다 — 요청조차 나가지 않습니다.

| | 받는 형식 | 상한 |
| --- | --- | --- |
| 그림 | JPEG · PNG · WebP | 3MB |
| 소리 | MP3 · M4A(AAC) | 10MB · 10분 |

형식은 **파일의 바이트**로 판정합니다. 확장자를 바꾼 파일은 통과하지 못하고, 영상 트랙이
들어 있는 `.mp4`는 소리로 받지 않습니다. 소리의 길이는 파일 크기와 **다른 축**이라 따로
막힙니다 — 낮은 비트레이트로 인코딩한 한 시간짜리 파일은 작지만 받지 않습니다.

### 이름은 실행 중에 골라도 됩니다

외부 주소와 갈리는 지점입니다. **이름은 실행 중에 만들어도 됩니다** — 그 이름이 이 작품에
올려 둔 이미지에 있으면 그림이 그려집니다.

```tsx
const face = trust > 3 ? "smile" : "angry";

<Image source={asset(`characters/sena/${face}`)} alt="세나" />
```

RowCat 자산은 우리 저장소를 가리키므로 그 이름이 밖으로 나가지 않습니다. 외부 주소는
그렇지 않아서 규칙이 다릅니다(아래 [주소는 프로젝트에 고정된
자산입니다](#주소는-프로젝트에-고정된-자산입니다)).

### 없는 이름은 자리표시자입니다

아직 올리지 않은 그림, 이름을 바꾸다 만 경로, 위처럼 조합했는데 그 조합이 없는 경우가
전부 같은 결과입니다 — **그림 자리가 비고 런타임 코드에는 아무 오류도 오지 않습니다.**
작품을 만드는 동안 이름이 잠깐 비어 있는 것은 정상이고, 그것 때문에 화면이 멈추지 않습니다.

### 자산을 바꾸면 다시 발행합니다

스튜디오에서 파일을 갈아 끼우거나 이름을 바꾸는 일은 **초안**을 고치는 일입니다. 이미
발행한 작품은 **다시 발행하기 전까지 그대로 보이고 들립니다** — 플레이 중인 사람의 화면이
갑자기 바뀌지 않습니다.

`파일 교체`는 **종류를 바꾸지 않습니다.** 그림 이름에는 그림만, 소리 이름에는 소리만 끼울
수 있습니다 — 종류를 바꾸려면 그 이름을 목록에서 빼고 다시 만듭니다.

이름을 바꿔도 **코드는 자동으로 고쳐지지 않습니다.** 소스에 적은 옛 이름은 그대로 남고,
그 자리는 위 규칙대로 자리표시자가 됩니다. 스튜디오는 이름을 바꾸기 전에 그 이름이 코드에
**직접 적힌** 자리가 몇 곳인지 알려 줍니다 — 이름을 조립해서 만든 자리
(``asset(`characters/sena/${face}`)``)는 셀 수 없으므로 그 수는 전부가 아닙니다.

### 목록에서 빼는 것과 지우는 것

스튜디오의 `목록에서 제거`는 **이 초안이 그 파일을 그 이름으로 부르던 사실**을 지웁니다.
올린 파일 자체는 지워지지 않고, 이미 발행한 작품도 다시 발행하기 전까지 그대로 보입니다.

## 외부 HTTPS 이미지

공개 인터넷에 올려 둔 그림의 주소를 `asset()`에 적으면 `Image`가 그 그림을 그립니다.

```tsx example=remote-image file=src/main.tsx
import { Image, Stack, Text, asset } from "@rowcat/runtime";

export default function App() {
	return (
		<Stack gap={12} style={{ padding: 16 }}>
			<Image
				source={asset("https://cdn.example.com/characters/sena.webp")}
				alt="세나"
				fit="cover"
				style={{ width: 96, height: 96, borderRadius: 48 }}
			/>
			<Text>세나가 카운터 뒤에서 고개를 들었다.</Text>
		</Stack>
	);
}
```

주소는 반드시 `asset()`을 지납니다. `<Image source="https://…" />`처럼 문자열을 그대로 넣으면
컴파일에서 막힙니다 — `asset()`은 *이 문자열은 이미지 참조다*라고 선언하는 자리이고, 그
자리에서 주소의 모양이 검사됩니다.

### 주소는 프로젝트에 고정된 자산입니다

**원격 이미지 주소는 소스에 그대로 적혀 있어야 합니다.** 런타임 중의 값이나 플레이어가 친
글로 외부 주소를 만들 수 없습니다.

```tsx
// 됩니다 — 소스에 적힌 주소 그대로입니다
<Image source={asset("https://cdn.example.com/sena.webp")} alt="세나" />
<Image source={asset("https://cdn.example.com/sena.webp?width=800")} alt="세나" />

const COVER = "https://cdn.example.com/cover.webp";
<Image source={asset(COVER)} alt="표지" />
```

```tsx
// 안 됩니다 — 실행 중에 만들어지는 주소입니다
<Image source={asset(`https://cdn.example.com/${name}.webp`)} alt="누구" />
<Image source={asset("https://cdn.example.com/" + name + ".webp")} alt="누구" />
```

안 되는 쪽은 컴파일이 막지 않습니다. 그 참조는 만들어지지만 **그림이 그려지지 않고**
자리표시자가 남습니다 — 아무 요청도 나가지 않습니다.

인물마다 다른 그림이 필요하면 주소를 **표로 적습니다.** 그러면 모든 주소가 소스에 있습니다.

```tsx
const FACE = {
	sena: asset("https://cdn.example.com/sena.webp"),
	minji: asset("https://cdn.example.com/minji.webp"),
} as const;

<Image source={FACE[who]} alt={who} />
```

이 규칙이 있는 이유는 원격 주소가 **당신의 서버로 나가는 값**이기 때문입니다. 주소의 경로와
질의는 그 서버에 도착하고, 거기에 플레이어가 친 글이나 진행 상태를 실을 수 있게 두면 런타임
코드가 밖으로 정보를 내보내는 통로가 됩니다. 그래서 나갈 수 있는 주소는 작품을 발행할 때
소스에서 확인된 것으로 고정됩니다.

### 주소의 규칙

| 규칙 | |
| --- | --- |
| 스킴 | `https://`만. `http://`, `data:`, `blob:`, `file:`, `javascript:`는 거절됩니다 |
| 호스트 | 공개 인터넷의 도메인 이름. IP 주소(`127.0.0.1`, `[::1]`)와 `localhost`는 거절됩니다 |
| 포트 | 기본 포트(443)만. `:8443` 같은 다른 포트는 거절됩니다 |
| 자격증명 | `https://user:password@…`는 거절됩니다 |
| 질의 | 됩니다. `?width=800&v=42` — 서명된 CDN 주소도 그대로 씁니다 |
| 조각 | `#…`는 거절됩니다 |
| 길이 | 최대 8,192자 |
| 글자 | 공백·제어 문자 없음. 비ASCII는 퍼센트 인코딩합니다 |
| 형식 | JPEG · PNG · WebP · GIF. SVG는 지원하지 않습니다 |

규칙 밖의 주소는 `runtime_invalid_asset_ref`로 그 자리에서 던집니다. 규칙 안이라도 그 주소가
사설망을 가리키거나 이미지가 아닌 것을 돌려주면 그림은 **자리표시자**로 그려집니다 — 런타임
코드에 오류가 오지 않습니다.

### 그림은 RowCat을 거쳐 옵니다

원격 이미지는 플레이어의 기기가 제작자의 서버에 직접 요청하지 않고 **RowCat의 이미지 경로를
통해** 불러옵니다.

그래서 당신의 서버에는 플레이어의 IP 주소나 브라우저·앱의 User-Agent가 직접 전달되지
않습니다. **다만 당신의 서버는 RowCat이 그 이미지를 요청했다는 사실과 그 시점은 볼 수
있습니다** — 어떤 그림이 언제 요청되었는지는 남습니다. 익명이 되는 것이 아니라 **플레이어의
접속 정보가 가려지는 것**입니다.

반대 방향으로는 아무것도 오지 않습니다. 당신의 서버가 어떤 응답을 했는지는 런타임 코드에
오지 않습니다 — `asset("https://…")`는 그림 하나를 그려 달라는 참조이지 `fetch()`가
아닙니다. [보안과 샌드박스](/docs/runtime/runtime-model/security)의 네트워크 절이 그 차이를
적습니다.

### 만료되는 주소

**만료되는 signed URL을 런타임 소스에 넣으면 URL이 만료된 뒤 이미지가 표시되지 않습니다.**
서명된 주소는 지원되지만 그 유효기간은 당신의 CDN이 정하고, 발행된 작품은 그 뒤에도 계속
플레이됩니다. 오래 남을 그림은 만료가 없는 공개 CDN 주소를 씁니다. RowCat이 만료된 주소를
갱신하거나 기억해 두지 않습니다.

### 비밀이 아닙니다

주소에 토큰처럼 보이는 값이 들어 있어도 **발행된 런타임 소스는 열어 볼 수 있습니다.**
비공개 CDN의 자격증명, 오래 사는 접근 토큰, 비밀로 남아야 할 서명 주소를 적지 마세요. 서명
주소를 쓴다면 작품을 열 자격이 있는 플레이어에게 보이는 값으로 취급합니다.

## 둘 중 무엇을 쓸까요

| | RowCat 자산 | 외부 HTTPS 주소 |
| --- | --- | --- |
| 받는 것 | 그림 · 소리 | **그림만** |
| 파일이 있는 곳 | RowCat | 당신의 CDN |
| 코드에 적는 것 | 이름 | 주소 전체 |
| 실행 중에 고르기 | 됩니다 | 안 됩니다(소스에 적힌 주소만) |
| 만료 | 없습니다 | 서명 주소는 당신의 CDN이 정합니다 |
| 파일 바꾸기 | 스튜디오에서 교체 → 다시 발행 | 당신의 CDN에서 교체 |

작품을 위해 만든 그림은 **RowCat 자산**이 낫습니다. 이미 다른 곳에서 서비스하고 있는
그림, 자주 바뀌는 그림, 당신이 따로 관리하는 그림은 외부 주소를 씁니다.

## `AssetRef`

`asset()`이 돌려주는 값은 **불투명**합니다. `.url`도 `.path`도 `.kind`도 없고, 문자열로
되돌릴 방법도 없습니다. 그 값으로 할 수 있는 일은 `Image`의 `source`에 넣는 것 하나입니다.

## `Image`의 프롭

| 프롭 | 뜻 |
| --- | --- |
| `source` | `asset()`이 만든 참조(필수) |
| `alt` | 스크린리더가 읽는 이름. 장식이면 생략 |
| `style` | 상자 스타일 |
| `fit` | `"cover"` · `"contain"` · `"fill"` |

불러오지 못한 그림(주소가 사라졌거나, 형식이 지원되지 않거나, 너무 크거나, **소스에 적힌
주소가 아니거나**)은 `alt`를 가진 자리표시자로 남습니다. 런타임 코드는 그 실패를 알 수 없고,
알 필요도 없게 되어 있습니다.
