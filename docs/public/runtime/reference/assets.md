# 자산

RowCat에 올린 파일(그림·소리)은 **이름**으로, 외부 그림은 **HTTPS 주소**로 가리킵니다.
근거와 예제는 [자산](/docs/runtime/concepts/assets)에 있습니다.

## `asset`

```ts
function asset(value: string): AssetRef;
```

문자열 하나를 참조로 봉인합니다. 검사는 그 자리에서 끝나고 네트워크도 저장소도 보지
않습니다 — 같은 문자열은 언제 불러도 같은 결과입니다.

받는 값은 둘입니다.

### HTTPS 이미지 주소

| 규칙 | |
| --- | --- |
| 선언 | **소스에 그대로 적힌 주소만.** 실행 중에 만들어진 주소는 자리표시자입니다 |
| 스킴 | `https://`만 (`http:`·`data:`·`blob:`·`file:`·`javascript:`·`//…` 거절) |
| 호스트 | 공개 인터넷의 도메인 이름 (IP 리터럴·`localhost` 거절) |
| 포트 | 443만 (`:443`은 됩니다) |
| 자격증명 | 없어야 합니다 |
| 질의 | 됩니다 |
| 조각(`#`) | 거절 |
| 길이 | 최대 8,192자 |
| 글자 | 공백·제어 문자 없음 · 비ASCII는 퍼센트 인코딩 |

### RowCat 자산 이름

**그림과 소리가 한 이름 공간을 나눠 씁니다.** 이름이 무엇을 가리키는지는 스튜디오에서
올릴 때 정해지고, 부르는 프리미티브가 그것을 바꾸지 않습니다.

| 규칙 | |
| --- | --- |
| 선언 | **실행 중에 만들어도 됩니다.** 그 이름이 이 작품에 올려 둔 자산에 있으면 열립니다 |
| 조각 | 영문이나 숫자로 시작, 영문·숫자·`.`·`_`·`-` |
| 깊이 | 최대 8단계 |
| 길이 | 최대 200자 |
| 개수 | 한 작품에 최대 256개 (그림과 소리를 **합쳐서**) |
| 거절 | 빈 값, 앞뒤 공백, `.`·`..` 조각, `:`·`\`가 든 값, 한 작품 안의 같은 이름 |

올릴 수 있는 파일:

| | 형식 | 상한 |
| --- | --- | --- |
| 그림 | JPEG · PNG · WebP | 3MB |
| 소리 | MP3 · M4A(AAC) | 10MB · 10분 |

규칙 밖의 값은 `runtime_invalid_asset_ref`로 던집니다.

## `AssetRef`

`asset()`이 돌려주는 불투명한 값. 공개 속성이 없고 문자열로 되돌릴 수 없습니다. 할 수 있는 일은
`Image`나 `Audio`의 `source`에 넣는 것뿐입니다.

## 그려지는 것

| 참조 | `Image` | `Audio` |
| --- | --- | --- |
| 발행본에 있는 **그림** 이름 | 그려집니다 | 침묵 |
| 발행본에 있는 **소리** 이름 | 자리표시자 | 울립니다 |
| 발행본에 없는 이름 | 자리표시자 | 침묵 |
| 소스에 적힌 HTTPS 주소 | RowCat의 이미지 경로를 거쳐 그려집니다. JPEG · PNG · WebP · GIF | **침묵 — 요청이 나가지 않습니다** |
| 실행 중에 만들어진 HTTPS 주소 | 자리표시자. 요청이 나가지 않습니다 | 침묵 |

**어긋난 종류는 오류가 아닙니다.** 소리 이름을 `Image`에 넣거나 그림 이름을 `Audio`에
넣으면 요청조차 나가지 않고, 런타임 코드에는 아무것도 오지 않습니다.

불러오지 못한 그림은 자리표시자로, 울리지 못한 소리는 침묵으로 남습니다.

원격 이미지는 RowCat이 대신 가져옵니다 — 플레이어의 IP 주소와 User-Agent는 원격 서버에
전달되지 않지만, 그 서버는 RowCat의 요청과 그 시점을 볼 수 있습니다.
[자산](/docs/runtime/concepts/assets#그림은-rowcat을-거쳐-옵니다)이 그 경계를 적습니다.
